# Gemini Baton

Claude Code plans and verifies, Gemini (Google Antigravity `agy` CLI) implements.

This plugin contains only a skill (`ajan`), a command (`/gemini-baton:devret`) and a subagent (`gemini-baton:ajan-yonetici`). They drive the separately installed `baton` CLI, which in turn runs `agy`. Task prompts and project files you hand off are sent to Google through `agy`.

Requirements, installation and usage: https://github.com/HSGunes/gemini-baton-for-claude-code#quick-start
